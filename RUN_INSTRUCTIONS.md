# Run Instructions (Local-Only)

## Option 1: Open directly in browser
1. Locate `Valenero CRM Pro — Command Center.html`.
2. Double-click it or drag it into a browser tab.
3. Data persists in browser localStorage.

## Option 2: Serve with Python
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000/Valenero%20CRM%20Pro%20%E2%80%94%20Command%20Center.html`.

## Option 3: VS Code Live Server
1. Open folder in VS Code.
2. Right-click the HTML file.
3. Click **Open with Live Server**.

## Notes
- Use topbar buttons for JSON backup export/import.
- Imports page supports CSV/XLSX leads and objection/script JSON imports.
